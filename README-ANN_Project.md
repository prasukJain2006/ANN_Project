# ANN Project

An Artificial Neural Network project built around the Iris dataset, with a notebook, a trained model, and a live prediction script.

## What is in this repo
- `project_ANN.ipynb` — model training notebook
- `live_project.py` — live prediction script
- `iris_model.h5` — trained ANN model
- `scaler.pkl` — scaler used for input features
- `requirements.txt` — Python dependencies

## How to run
1. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the live script:
   ```bash
   python live_project.py
   ```
